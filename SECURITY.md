# Security Policy

## Supported Versions

Only the latest release receives security updates.

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

If you find a security vulnerability, please **do not open a public issue**.

Instead, report it privately via GitHub's
[private vulnerability reporting](https://github.com/USER/pomosprint/security/advisories/new)
or by email at 73265adk@gmail.com but please note that e-mails unrelated to security reports will not be processed.

I'll try to respond within a few days. If the issue is confirmed, I'll work
on a fix and credit you in the release notes (unless you prefer to stay anonymous).
